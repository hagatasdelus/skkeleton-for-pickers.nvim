INTRODUCTION						*skkeleton-pickers-introduction*

skkeleton-pickers.nvim is a Neovim plugin that provides seamless integration
between the skkeleton Japanese input method and popular fuzzy finders, enabling
smooth Japanese text input within prompt buffers.

Normally, keymaps and modes of SKK can conflict with the prompt behavior of
fuzzy finders. This plugin resolves those conflicts, allowing you to use SKK
Japanese input in fuzzy finders stress-free.

Features: ~

- Seamless Input Experience: Automatically enables SKK mode when entering the
  prompt window.
- Safe <CR> Forwarding: Enter key confirms active preedit character, but
  selects/opens items on empty preedit text.
- Dynamic Marker Support: Tracks skkeleton configuration markers dynamically.
- Out-of-the-box support for Telescope and mini.pick.

==============================================================================
REQUIREMENTS						*skkeleton-pickers-requirements*

- Neovim >= 0.11.0 (or Neovim >= 0.12.0 for built-in vim.pack)
- vim-denops/denops.vim (https://github.com/vim-denops/denops.vim)
- vim-skk/skkeleton (https://github.com/vim-skk/skkeleton)

==============================================================================
INSTALLATION						*skkeleton-pickers-installation*

Using lazy.nvim: >lua

  {
    "hagatasdelus/skkeleton-pickers.nvim",
    dependencies = { "vim-skk/skkeleton" },
    config = function()
      require("skkeleton-pickers").setup({
        pickers = {
          telescope = { enabled = true },
        },
      })
    end
  }
<
Using mini.deps: >lua

  local MiniDeps = require('mini.deps')
  MiniDeps.add({
    source = 'hagatasdelus/skkeleton-pickers.nvim',
    depends = { 'vim-skk/skkeleton' },
  })
  require('skkeleton-pickers').setup({
    pickers = {
      telescope = { enabled = true },
    },
  })
<
Using vim.pack (Neovim 0.12+): >lua

  vim.pack.add({
    source = "hagatasdelus/skkeleton-pickers.nvim",
    depends = { "vim-skk/skkeleton" },
  })
  require("skkeleton-pickers").setup({
    pickers = {
      telescope = { enabled = true },
    },
  })
<

==============================================================================
CONFIGURATION						*skkeleton-pickers-configuration*

Note: All pickers are disabled by default (`enabled = false`). You must
explicitly enable each picker in setup().

Customize options inside setup(): >lua

  require("skkeleton-pickers").setup({
    pickers = {
      telescope = { enabled = false },
      mini_pick = { enabled = false },
    },
  })
<

==============================================================================
NOTES							*skkeleton-pickers-notes*

Escape key (<Esc>) handling in mini.pick: ~
In mini.pick integration, pressing <Esc> during henkan or input state internal-
ly routes \x07 (<C-g>) to skkeleton instead of \x1b to prevent skkeleton from
being disabled and to properly cancel active preedit text.
* Note: Future updates or specification changes in skkeleton or mini.pick
  may alter or deprecate this cancel routing behavior.
